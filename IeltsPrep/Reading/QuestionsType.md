# IELTS Reading Question Types

## 1. Matching Questions

### 1.1 Matching Headings
- Pick the best title or heading for each paragraph or section of the passage.

### 1.2 Matching Information
- Identify which paragraph contains specific facts, details, examples, or pieces of information.

### 1.3 Matching Features
- Match items from a list (e.g., people, places, dates, or theories) to the correct statements or descriptions.

### 1.4 Matching Sentence Endings
- Complete sentences by matching the first half with the correct ending from a list of options.

---

## 2. True / False / Yes / No Questions

### 2.1 True / False / Not Given
- **True** – The statement agrees with the factual information in the passage.
- **False** – The statement contradicts the information in the passage.
- **Not Given** – The passage does not provide enough information to determine whether the statement is true or false.

### 2.2 Yes / No / Not Given
- **Yes** – The statement agrees with the writer's opinion or claim.
- **No** – The statement contradicts the writer's opinion or claim.
- **Not Given** – The writer's opinion is not mentioned.

---

## 3. Completion Tasks

### 3.1 Sentence Completion
- Complete sentences using words taken directly from the passage.

### 3.2 Summary / Note Completion
- Fill in the missing words in a summary or notes using information from the passage.

### 3.3 Table / Flow Chart / Diagram Completion
- Complete a table, flow chart, or diagram with information from the reading passage.

---

## 4. Choice and Short Answer Questions

### 4.1 Multiple Choice
- Choose the correct answer (A, B, C, or D).
- Some questions may require selecting more than one correct option.

### 4.2 Short Answer Questions
- Answer the questions using no more than the specified number of words from the passage.

### 4.3 Choosing a Title
- Select the most appropriate title or main idea for the entire reading passage.
