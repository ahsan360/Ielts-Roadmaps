# Topic

**Describe a challenging technological problem you faced.**

## AAA Method

### A — Answer

I'd like to talk about a challenging technological problem I faced while working as a **software engineer**. It happened when I was working on a web application that was being used by a large number of users. The main problem was that some of the pages and API responses were **extremely slow**, particularly during busy periods.

### A — Add Details

At first, I found the problem quite difficult because there wasn't any obvious error in the application. Everything appeared to be working normally, but some requests were taking several seconds to complete.

I started investigating the problem by checking the application logs and analysing the database queries. Eventually, I discovered that some of the queries were unnecessarily complicated and were retrieving more data than the application actually needed. In addition, several important database fields were not properly indexed.

I then **optimised the queries, improved the database structure, and added appropriate indexes**. After making these changes, I tested the application under different conditions to make sure that the solution was reliable.

### A — Anecdote

I particularly remember one evening when I was trying to identify the source of the problem. I had already spent several hours checking the application code, but I couldn't figure out why the responses were so slow. I was becoming quite frustrated because the problem seemed relatively simple, yet I couldn't find the root cause.

Eventually, I noticed that one database query was taking much longer than the others. I examined it carefully and realised that it was unnecessarily fetching a large amount of data. After rewriting the query, the response time improved dramatically.

**That experience taught me that solving a technical problem isn't always about writing more code. Sometimes, the key is to investigate the problem systematically and identify its underlying cause.** It also strengthened my problem-solving skills and made me much more confident as a software engineer.
